## 技術層面

### 反覆踩到的陷阱

**1. thin block 陷阱**

`**Bold** text...` 起頭的段落，因起始字元是 `*` 被 `_count_thin_blocks()` 排除計數。整個 section 可能有 4 段卻被判定為 0 prose lines。解法：所有段落改用普通文字起頭。

**2. 年份偵測陷阱**

`1987年` 中「年」是 Unicode `\w`，`\b` 不成立，年份不被計入。須寫 `1987 年`（加空格）才能偵測到。

**3. 套路結尾窗口**

`_detect_formulaic_ending()` 掃最後 5 行合格行（過濾標題/bullet/含 URL 行）。即使問題句在文章中段，只要過濾後落入最後 5 行就觸發。

**4. blockquote 不保護**

`body_without_protected()` 只排除 code block 與 URL，不排除 blockquote。`> **30 秒概覽：**` 內的塑膠句仍計入 prose-health。
